# Structure from Motion and Visual Localization

Academic computer vision project focused on sparse 3D reconstruction and camera localization using HLOC.

## Tasks

- Created a custom indoor image dataset
- Extracted visual features from images
- Matched features between image pairs
- Generated a sparse 3D reconstruction
- Localized query images inside the reconstructed scene
- Compared DISK and SuperPoint configurations

## Results

The SuperPoint-based configuration provided significantly faster feature processing for the selected dataset and produced better visual coverage of several scene objects.

The DISK configuration generated a denser point cloud but required substantially more processing time.

## Technologies

- HLOC

- SuperPoint

- Structure from Motion
- Visual localization
