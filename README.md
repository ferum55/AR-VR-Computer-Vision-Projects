# AR, VR and Computer Vision Academic Projects

Academic projects completed as part of the AR/VR Programming course at Lviv Polytechnic National University.

## Projects

### WebXR AR Object Placement

Browser-based augmented reality prototype developed using TypeScript, Three.js and WebXR. Includes surface hit testing, a placement reticle, GLTF loading and interactive placement of a 3D object.

[View project](./Lab-1-WebXR-AR)

### Optical Flow and Motion Tracking

Python and OpenCV application implementing dense optical flow visualization and sparse Lucas-Kanade feature tracking.

[View project](./Lab-3-Optical-Flow)

### Structure from Motion and Visual Localization

HLOC-based project covering feature extraction, image matching, sparse 3D reconstruction and camera localization using a custom indoor dataset.

[View project](./Lab-5-Structure-from-Motion)

## Technologies

- TypeScript
- Three.js
- WebXR
- Python
- OpenCV
- HLOC
- COLMAP
- SuperPoint
- DISK

These projects were developed for academic and experimental purposes. Some projects require specific devices, datasets or environment configurations.
