# WebXR AR Object Placement

Academic augmented reality prototype developed using TypeScript, Three.js and WebXR.

## Functionality

- Starts an immersive WebXR AR session
- Requests a local reference space
- Performs surface hit testing
- Displays a reticle on detected surfaces
- Loads a GLTF 3D model
- Places a copy of the model after user interaction
- Renders the model inside the AR environment

## Technologies

- TypeScript
- Three.js
- WebXR Device API
- WebGL2
- GLTFLoader

## Requirements

The project requires a device and browser with support for immersive WebXR AR sessions and hit testing.

## Project Status

Academic prototype. The source code is provided primarily as a demonstration of practical experience with WebXR, Three.js and browser-based augmented reality.
